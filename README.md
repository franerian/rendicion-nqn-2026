# Informe de gestión · Rendición de cuentas Neuquén 2026

Presentación en scroll de un solo HTML (`scroll/informe-scroll.html`), pensada para proyectarse en 2160×1080.

- **Sitio publicado:** https://rendicionnqn2026.vercel.app (proyecto Vercel `rendicionnqn2026`)
- **Medios:** las imágenes y los videos (`scroll/img`, `scroll/video`) **no están en este repo**; se sirven desde el deploy de Vercel. El repo guarda solo el código.
- **Publicar:** `herramientas/publicar.sh --pantallas "NN"` (sube a Vercel y verifica). El repo no despliega solo.
- **Herramientas:** `herramientas/` (medir, publicar, exportar PDF/ZIP). Detalle en `herramientas/LEEME.md` y `CLAUDE.md`.
- `_base-v121/`: fuente y HTML publicado de la v121, para volver atrás.
